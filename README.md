# NEU Library Visitor App

A web application to log and track visitors to the **NEU Library**.  
Visitors can check in by selecting their college, role, and purpose of visit.  
Administrators can view visitor logs, filter by college, purpose, or role, and monitor visits in real-time.

---

## Features

- Visitor check-in with email verification (`@neu.edu.ph`)
- Role selection (Student, Faculty, Staff, Visitor)
- Purpose of visit selection
- Admin dashboard with visitor logs, filters, and statistics
- Recent visit history for each visitor
- Fully hosted on Firebase Hosting

---

## Live Application

Access the live application here: [https://neu-library-visitor.web.app](https://neu-library-visitor.web.app)

---

## Technologies Used

- HTML, CSS, JavaScript
- Firebase (Firestore + Hosting)
- Firebase JS SDK v12

---

## How to Use

1. Go to the [live application](https://neu-library-visitor.web.app)  
2. Select your College, Role, and Purpose of Visit  
3. Enter your NEU email  
4. Click **Login & Check In** to register your visit  
5. Admins can click **Go to Admin Dashboard** to view and filter all visitor logs
